# Dernek Yönetim Sistemi – Kurulum

Bu sayfada yalnızca programın kurulum dosyaları bulunur. Program kodu ve dernek kayıtları burada **yoktur**.

## İndirme

**[En son sürümü indir](https://github.com/UmutGuvenUslu/dernek-yonetim-sistemi-kurulum/releases/latest)**

Açılan sayfada **Dernek-Yonetim-Sistemi-Setup.exe** dosyasına tıklayın.

- `Dernek-Yonetim-Sistemi-Setup.exe`: Bilgisayara kurulur, masaüstüne kısayol ekler. Normal kullanım için bunu indirin.
- `Dernek-Yonetim-Sistemi-Tasinabilir.exe`: Kurulum gerektirmez, doğrudan çalışır.

## Kurulum

1. Setup dosyasını çalıştırın. Windows "bilgisayarınız korundu" uyarısı verirse **Ek bilgi > Yine de çalıştır** seçin.
2. Kurulumdaki önemli notları okuyun ve kurulumu tamamlayın.
3. Program ilk açıldığında **Yedeğimi Yükle** seçip size verilen yedek dosyasını (.zip) gösterin.

Dernek kayıtları güvenlik nedeniyle programla birlikte gelmez; yalnızca yetkili kişilere verilen yedek dosyasıyla yüklenir.

## Güncelleme

1. Programda **Yedekleme > Yedek Al** ile flash belleğe yedek alın.
2. Bu sayfadan yeni Setup dosyasını indirip eskisinin üzerine kurun. Verileriniz silinmez.

Gereksinim: Windows 10 veya 11 (64 bit).
